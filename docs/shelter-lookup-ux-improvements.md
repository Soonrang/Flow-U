# 보호소 조회 UX/UI 개선안

## 목표

보호소 조회 흐름을 개선해 사용자가 주변 보호소를 빠르게 훑고, 선택한 보호소를 지도 안에서 맥락 있게 확인하며, 다음 행동까지 자연스럽게 이어갈 수 있도록 한다.

## 개선 목록

1. 보호소 목록 카드 간소화
   - 목록 카드는 빠른 스캔에 집중한다.
   - 보호소명, 동물 타입, 거리, 짧은 주소만 보여준다.
   - 전화번호와 운영시간은 상세 화면에서 확인하도록 분리한다.

2. 선택된 보호소 마커 강조
   - 목록 또는 지도에서 보호소를 선택하면 해당 마커를 시각적으로 강조한다.
   - 테두리, 크기, 그림자를 강화해 선택한 보호소와 지도 위치가 바로 연결되게 한다.

3. 보호소 상세 주요 액션 추가
   - 전화하기, 주소 복사, 카카오맵에서 보기, 길찾기 같은 행동 버튼을 추가한다.
   - 모바일에서는 전화하기와 길찾기를 우선 배치한다.

4. 가벼운 필터 추가
   - 전체, 강아지, 고양이 필터 칩을 추가한다.
   - 이후 필요하면 가까운 순, 운영 중 같은 정렬/상태 필터를 확장한다.

5. 빈 상태 개선
   - 검색 결과가 없을 때 더 친절한 안내 문구를 보여준다.
   - 검색어가 입력된 상태라면 검색 초기화 버튼을 함께 제공한다.

6. 내 위치 기능 피드백 강화
   - 위치 확인 중 상태를 명확히 보여준다.
   - 현재 위치 이동 성공 시 짧은 성공 피드백을 제공한다.
   - 권한 거부나 타임아웃은 사용자가 이해하고 조치할 수 있는 문구로 안내한다.

7. 이 지역에서 다시 보기 기능 추가
   - 사용자가 지도를 드래그하면 현재 지도 중심 기준으로 다시 볼 수 있는 작은 버튼을 띄운다.
   - 지도의 움직임과 목록 정렬 변화가 의도적으로 느껴지게 한다.

8. 바텀시트 상세 화면 구조 정리
   - 상세 화면을 보호소명, 뒤로가기, 동물 타입, 거리, 주소, 전화번호, 운영시간, 설명, 액션 순서로 정리한다.
   - 뒤로가기 버튼은 상단 오른쪽에 유지해 이전 목록 화면으로 쉽게 돌아가게 한다.

## 진행 순서

1. 보호소 목록 카드 간소화
2. 선택된 보호소 마커 강조
3. 보호소 상세 주요 액션 추가
4. 동물 타입 필터 추가
5. 빈 상태 개선
6. 내 위치 기능 피드백 강화
7. 이 지역에서 다시 보기 추가
8. 사용 피드백을 바탕으로 상세 화면 구조 정리
